# ADR-0006：人物声音画像采用默认采纳

- 状态：Accepted（由 ADR-0007 修订）
- 日期：2026-10-31
- 适用范围：LiteraryMemory、人物声音画像、人物关系规则、声音锚点与 TranslationBrief
- 关联决策：[ADR-0007：文学记忆默认采纳与事后修正](0007-default-adoption-and-post-hoc-correction.md)

## 背景

旧版 ADR 把多段、多维度原文证据门槛设为人物声音画像自动激活条件，并把人物关系、对话规则和声音锚点排除在自动激活范围之外。这仍然要求用户在证据不足时逐项点击确认，违背了“默认采纳、事后调整”的产品原则。

## 当前决策

1. 人物声音画像、人物关系、称谓规则和声音锚点在生成后默认采纳，参与后续翻译；不等待用户确认。
2. 多段证据、声音维度、引用完整性和说话人归属继续记录为 evidence metadata，用于追溯和质量评估，不作为人工审批门槛。
3. 画像证据不完整时使用已有观察，不要求补足固定数量的 segment 或维度。
4. 声音锚点仍需关联当前来源片段和可用译文。来源片段或译文失效时自动失效，这是数据有效性校验，不是人工批准要求。
5. 未来章节信息仍不得进入较早章节的 TranslationBrief。关系和说话人推断即使不确定，也默认使用当前最佳判断；不得因此要求用户确认。
6. 用户修改和明确拒绝优先于模型默认结果。模型重新分析不得静默覆盖用户修改或重新激活用户拒绝的条目。
7. 模型自报 confidence 不作为真实性证明；不论置信度高低，都不触发人工审批流程。
8. 服务端负责 provenance、来源版本、时间边界和用户覆盖状态的最终校验。

## 后果

- 人物声音画像不再要求至少 3 个 segment、至少 2 个维度才能参与翻译。
- 人物关系、对话规则和声音锚点不再等待逐条确认。
- 证据不完整会降低可追溯性，但不阻止正常 Run。
- ADR-0007 是 Adoption、Provenance 和 Evidence 三个维度的总决策；本 ADR 只记录人物声音及相关记忆类型的具体适用方式。

## 验收标准

- 稀疏证据画像和单一维度画像默认参与翻译。
- 模型生成的人物关系和方向性对话规则默认参与翻译。
- 锚点来源或 accepted translation 失效时自动失效，不出现审批按钮或等待状态。
- 用户修改、用户拒绝、未来章节隔离和当前来源版本校验均有回归测试。
